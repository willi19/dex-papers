Towards Affordance-Aware Robotic Dexterous Grasping with Human-like Priors

AAAI 2026Wuhan University · DAMO Academy RL + ILdexterous grasping human motion prioraffordance

Official AffordDex pipeline: human-motion pretraining, negative-affordance extraction, residual RL, and teacher–student distillation.

TL;DR

AffordDex learns a dynamic grasp that is stable, looks human-like, and avoids functionally wrong contact regions—for example, holding a knife by its handle rather than its blade.

Problem

  • Standard grasp policies optimize lift success and geometric stability.
  • They can produce unnatural finger poses or grasp a semantically wrong part.
  • A useful grasp should also prepare the object for safe downstream manipulation.

Output

  • A full Shadow Hand grasping trajectory, not only a static final pose.
  • The vision policy observes robot state, scene point cloud, and forbidden-contact points.
  • It approaches, closes the hand, and lifts the object to a target.

Training pipeline

  1. Human prior: learn natural robot-hand motion from roughly 2,200 right-hand sequences in OakInk2.
  2. Negative affordance: identify object regions that should not be touched, such as a knife blade.
  3. Residual teacher: freeze the human-motion policy and use PPO to learn object-specific corrections with privileged state.
  4. Vision student: distill the teacher with DAgger into a policy that does not observe ground-truth object state.

Key equations

1 · Human-motion prior

rᴴ = λ_finger rᴴ_finger + λ_smooth rᴴ_smooth rᴴ_finger = Σ_f w_f exp(−λ_f ‖j_robot,f − j_human,f‖²)

Meaning: match corresponding robot and MANO hand keypoints while discouraging high-power, jerky motion. This learns how a human-like grasp should move, but not yet how it should adapt to a particular object.

2 · Residual action

Δa_t = πᵀ(R_t, O_t, P_t, N_t) a_t = πᴴ(R_t, O_t, P_t) + Δa_t

R: robot state · O: privileged object state · P: scene point cloud · N: negative-affordance point cloud. The frozen human prior proposes the coarse action; the teacher changes only what the object and contact constraints require.

3 · Teacher reward

rᵀ = −r_distance − r_goal + r_success − r_negative

The policy approaches and lifts the object while being penalized for moving toward forbidden regions. The unusual term is r_negative; the other grasp and goal terms are standard.

4 · Vision distillation

πˢ = arg min_π ‖πᵀ(Sᵀ_t) − π(Sˢ_t)‖ Sᵀ_t = {R_t, O_t, P_t, N_t} Sˢ_t = {R_t, P_t, N_t}

DAgger trains the student to reproduce the privileged teacher while removing ground-truth object pose from the deployed observation.

How negative affordance is produced

  1. Apply plausible textures to the raw object mesh and render six fixed views.
  2. Ask GPT-4V which semantic part should not be touched.
  3. Use SAM to generate part-mask candidates.
  4. Use CLIP to select the mask matching the forbidden-part description.
  5. Project that mask back into a 3D point cloud used by the policy and reward.

This is an offline preprocessing step, reported at about 160 seconds per object on an RTX 4090.

What is actually new

  • Naturalness and function are decoupled: human demonstrations supply the motion manifold; RL supplies object-specific physical correction.
  • Affordance is expressed as a negative constraint: “do not touch this region” is easier to generalize than enumerating every valid functional grasp.
  • The semantic constraint enters control: the 3D negative region is an observation and a reward term, rather than only a grasp-ranking heuristic.

Reported evidence

  • Isaac Gym, Shadow Hand, 4,096 parallel environments.
  • Vision success: 87.0% seen objects, 82.8% unseen instances, 79.2% unseen categories.
  • Human-motion prior and NAA improve different axes in the ablation: pose naturalness and contact appropriateness.

Limitations

  • “Affordance-aware” mainly means avoiding a negative region, not selecting grasps from a downstream language instruction.
  • Six rendered views can miss concave or occluded functional parts.
  • Evaluation is simulation-centered; the paper does not report a real-robot benchmark.
  • Human-likeness is scored by Gemini 2.5 Pro, so it is softer evidence than physical success.

Takeaway

  • Classification: grasping paper with an IL motion prior, PPO residual learning, and DAgger distillation—not a VLA.
  • Distinctive idea: keep a human-like base policy fixed and learn only the residual needed to obey object geometry and semantic “do not touch” constraints.

Towards Affordance-Aware Robotic Dexterous Grasping with Human-like Priors

AAAI 2026Wuhan University · DAMO Academy RL + ILdexterous grasping human motion prioraffordance

Official AffordDex pipeline: human-motion pretraining, negative-affordance extraction, residual RL, and teacher–student distillation.

TL;DR

AffordDex learns a dynamic grasp that is stable, looks human-like, and avoids functionally wrong contact regions—for example, holding a knife by its handle rather than its blade.

Problem

  • Standard grasp policies optimize lift success and geometric stability.
  • They can produce unnatural finger poses or grasp a semantically wrong part.
  • A useful grasp should also prepare the object for safe downstream manipulation.

Output

  • A full Shadow Hand grasping trajectory, not only a static final pose.
  • The vision policy observes robot state, scene point cloud, and forbidden-contact points.
  • It approaches, closes the hand, and lifts the object to a target.

Training pipeline

  1. Human prior: use PPO and trajectory-tracking rewards to imitate roughly 2,200 right-hand sequences from OakInk2. This is RL-based motion imitation, not plain behavior cloning.
  2. Negative affordance: preprocess each object into a 3D point set marking regions that should not be touched, such as a knife blade.
  3. Residual teacher: freeze the human-motion policy and train a second PPO policy that adds 24D object-specific corrections using privileged object state.
  4. Vision student: use DAgger to distill the combined teacher behavior into a policy that sees partial point clouds but not ground-truth object pose or velocity.

Method details

Human-motion prior

The reference is a complete human grasping trajectory rather than a terminal grasp pose. Robot and MANO hands are matched through corresponding keypoints. Base joints use a sharper distance decay (λ = 50) than middle joints (λ = 40), and a power penalty discourages both aggressive acceleration and braking. After this stage, πᴴ is frozen.

Negative Affordance-aware Segmentation

TexPainter first gives the raw mesh plausible texture, after which six cardinal views are rendered. GPT-4V names one non-touchable part. On every view, a 16 × 16 point grid prompts SAM; NMS with IoU 0.7 removes duplicate masks. Each remaining mask is turned into a visual prompt by blurring its exterior, and CLIP selects the candidate most similar to the negative-part description. The chosen 2D masks are projected back into a 3D point cloud.

Residual policy

In the paper, the frozen πᴴ supplies a human-like nominal 24D action and πᵀ supplies a 24D correction. Both operate on the Shadow Hand’s 6 global wrist DOFs and 18 active finger DOFs. The released ResActorCritic, however, concatenates the two 24D outputs and applies a learned Linear(48, 24); it does not implement the printed element-wise sum literally.

Privileged-to-vision distillation

The teacher has perfect object position, rotation, velocity, and a 64D object feature. The student instead receives a 1,024-point partial hand–object cloud reconstructed from five fixed RGB-D cameras. The released training command selects a PointNet encoder; a PointNet+Transformer alternative also exists. State policies use four-layer MLPs with widths 1024–1024–512–512.

Paper–code discrepancy

  • The paper never specifies the numerical dimensions of R, O, P, or N. The dimensions above come from tensor slicing in the released repository, not from the PDF.
  • The released student point tensor contains xyz, RGB, a hand mask, and an object mask. It contains no explicit negative-affordance mask or separate N point set.
  • The released state task’s reward code contains distance, lifting, goal, and success terms, but no distance-to-N penalty matching the paper’s supplementary equation.
  • The provided state-training script runs a standard 300D→24D PPO actor. A residual actor class exists under the separate ppo_pose path, but that is not the path selected by the script documented for residual training.

Key equations

1 · Human-motion prior

rᴴ = 0.8 rᴴ_finger + 0.05 rᴴ_smooth rᴴ_finger = Σ_f w_f exp(−λ_f ‖j_robot,f − j_human,f‖²) rᴴ_smooth = −w_smooth Σ_i |τ_t,i · q̇_t,i|

Meaning: match corresponding robot and MANO keypoints while penalizing instantaneous actuator power. This constrains πᴴ to natural trajectories but does not yet say which object region is functionally safe.

2 · Residual action

Δa_t = πᵀ(R_t, O_t, P_t, N_t) a_t = πᴴ(R_t, O_t, P_t) + Δa_t

R: robot state · O: privileged object pose and velocity · P: scene/object geometry · N: negative-affordance point cloud. This is the paper’s interface; the released tensor interface differs as documented above.

3 · Teacher reward

rᵀ = −r_distance − r_goal + r_success − r_negative

Conceptually, distance-to-object and distance-to-goal are costs, success is a sparse bonus, and forbidden contact is a cost. The unusual signal is r_negative; the other three are standard goal-conditioned grasp rewards.

4 · Exact negative-affordance penalty

r_negative = λ_n Σ_{f ∈ fingertips} 𝟙[min_{p_n ∈ N} ‖p_tip^f − p_n‖ < α_n] α_n = 0.03 m, λ_n = −10

Meaning: every fingertip entering within 3 cm of any forbidden point incurs a discrete penalty. This is not a smooth repulsive field and does not reason about palm or link contact.

5 · Goal and success terms

r_goal = λ_g ‖p_object − p_goal‖, λ_g = −1 r_success = λ_s 𝟙[‖p_object − p_goal‖ < 0.05], λ_s = 1

Meaning: move the object toward a fixed goal and add a success bonus inside a 5 cm radius. These terms provide lifting performance; negative affordance only changes where the hand is allowed to contact.

6 · Vision distillation

πˢ = arg min_π ‖πᵀ(Sᵀ_t) − π(Sˢ_t)‖ Sᵀ_t = {R_t, O_t, P_t, N_t} Sˢ_t = {R_t, P_t, N_t}

DAgger trains the student to reproduce the privileged teacher while removing ground-truth object pose from the deployed observation.

Teacher reward in operational form

rᵀ ≈ −‖p_hand − p_object‖ − ‖p_object − p_goal‖ + 𝟙[‖p_object − p_goal‖ < 0.05] − 10 Σ_f 𝟙[min_{p ∈ N} ‖p_tip^f − p‖ < 0.03]
  • Approach: remaining far from the object continuously reduces return.
  • Transport: after contact, moving the object closer to the goal continuously improves return.
  • Finish: entering the 5 cm goal radius adds a sparse +1 bonus.
  • Avoid N: each fingertip entering 3 cm of the forbidden point set incurs −10. The check is binary and covers fingertips, not the palm or intermediate links.

Why the terms do not make the hand avoid the object entirely

The policy cannot maximize return by staying away: doing so keeps both distance costs large and makes the success bonus unreachable. Approaching a forbidden region is expensive, but approaching an allowed region reduces the grasp cost and enables goal transport. The resulting objective is therefore “touch the object, but not N.” For example, a successful safe state with 2 cm hand–object distance and 3 cm goal distance scores approximately −0.02 − 0.03 + 1 = 0.95; one forbidden fingertip changes it to approximately −9.05.

Two caveats: the printed reward contains no explicit −‖Δa‖² term, so the residual is not directly forced to remain small. Also, the main equation places minus signs outside the distance and affordance terms while the supplement assigns their λ values negative signs. Applying both literally would double-negate the costs; the text and ablations clearly describe the operational interpretation above.

How negative affordance is produced

  1. Apply TexPainter to the raw mesh and render six fixed views.
  2. Ask GPT-4V to name one object part that should not be touched.
  3. Prompt SAM with 256 regularly spaced points per view, then remove overlapping proposals with NMS.
  4. Blur everything outside each candidate mask and ask CLIP to rank the resulting visual prompts against the part description.
  5. Project the best masks into a 3D negative-affordance point cloud used by both policy observation and reward.

This is an offline preprocessing step, reported at about 160 seconds per object on an RTX 4090.

What is actually new

  • Naturalness and function are decoupled: human demonstrations supply the motion manifold; RL supplies object-specific physical correction.
  • Affordance is expressed as a negative constraint: “do not touch this region” is easier to generalize than enumerating every valid functional grasp.
  • The semantic constraint enters control: the 3D negative region is an observation and a reward term, rather than only a grasp-ranking heuristic.

Common machinery vs. paper-specific idea

  • Common: PPO, distance-to-object reward, distance-to-goal reward, sparse success bonus, privileged teacher, PointNet-style point-cloud encoder, and DAgger distillation.
  • Borrowed pattern: freezing a nominal policy and learning an additive residual is a standard way to limit RL exploration.
  • Specific to AffordDex: the nominal policy is trained on full human grasp trajectories, while an automatically generated forbidden-region point cloud conditions and rewards the residual.
  • Important non-claim: NAA does not infer the desired downstream task from language at run time; it assigns one offline “do not touch” region per object.

Reported evidence

  • Isaac Gym, Shadow Hand, 4,096 parallel environments.
  • Vision success: 87.0% seen objects, 82.8% unseen instances, 79.2% unseen categories.
  • State success: 89.2% / 87.7% / 85.2% over the same three UniDexGrasp splits.
  • Ablation separates the roles: HTI mostly raises human-likeness, NAA reduces forbidden contacts, and distillation recovers vision success.

Limitations

  • “Affordance-aware” mainly means avoiding a negative region, not selecting grasps from a downstream language instruction.
  • Six rendered views can miss concave or occluded functional parts.
  • The penalty checks fingertips within 3 cm of N; inappropriate palm or intermediate-link contact is not represented by that equation.
  • Evaluation is simulation-centered; the paper does not report a real-robot benchmark.
  • Human-likeness is scored by Gemini 2.5 Pro, so it is softer evidence than physical success.
  • The supplementary reward definitions already use negative coefficients while main-text Eq. (4) adds explicit minus signs. The intended costs are clear, but the printed sign convention is internally inconsistent.

Takeaway

  • Classification: grasping paper with an IL motion prior, PPO residual learning, and DAgger distillation—not a VLA.
  • Distinctive idea: keep a human-like base policy fixed and learn only the residual needed to obey object geometry and semantic “do not touch” constraints.
